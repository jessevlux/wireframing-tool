# Wireframing Tool - AI Assistant Rules

Dit beleid biedt duidelijke regels voor AI assistenten die werken aan deze Vue.js wireframing tool.

# 1. Project Overzicht

**Type**: Vue.js Wireframing Tool - SPA voor het maken en beheren van wireframe projecten
**Doel**: Gebruikers kunnen projecten aanmaken met pagina's en blokken, opslaan in localStorage, exporteren naar JSON

## 1.1 Technologie Stack

- **Vue 3** (v3.5.22) met Composition API (`<script setup>`)
- **Vite** (v7.1.7) voor build tooling
- **Vue Router** (v4.5.1) voor navigatie
- **Pinia** (v3.0.3) - optioneel, nog niet in gebruik
- **Tailwind CSS** (v4.1.15) voor styling
- **lucide-vue-next** voor icons
- **JavaScript** (geen TypeScript)

## 1.2 Project Structuur

```
src/
├── assets/          # CSS (main.css, base.css)
├── components/      # Herbruikbare componenten (PascalCase.vue)
├── views/           # Pagina views (*View.vue)
├── router/          # Router config (index.js)
├── stores/          # Pinia stores (optioneel)
├── App.vue          # Root component
└── main.js          # Entry point
```

# 2. AI Assistant Principes

## 2.1 Workflow

1. **Analyse**: Begrijp probleem, stel vragen bij onduidelijkheden
2. **Planning**: Presenteer stap-voor-stap plan, **wacht op goedkeuring**
3. **Implementatie**: Één stap per keer, toon resultaat, **vraag bevestiging**
4. **Review**: Behandel feedback, maak aanpassingen

## 2.2 Kernregels

- **ALTIJD verificatie met gebruiker voordat je implementeert**
- **95% zeker** zijn van aanpak voordat je doorgaat
- **Stap-voor-stap**, nooit alles in één keer
- Bij problemen: **stop onmiddellijk**, leg uit, wacht op instructies
- Bij twijfel: **vraag**, aanneem niet

## 3.3 Naming Conventies

- **Componenten**: PascalCase (bijv. `ProjectCard.vue`)
- **Views**: PascalCase + View suffix (bijv. `DashboardView.vue`)
- **Variabelen/Functies**: camelCase (bijv. `filteredProjects`)
- **Booleans**: is/has/should prefix (bijv. `isLoading`)
- **Handlers**: handle/on prefix (bijv. `handleClick`)
- **Events**: kebab-case (bijv. `@project-deleted`)
- **Constants**: UPPER_SNAKE_CASE

## 3.4 Import Volgorde

1. Vue core (`vue`, `vue-router`, `pinia`)
2. External dependencies (`lucide-vue-next`)
3. Components (relatieve paden)
4. Utils/helpers

# 4. Vue Composition API

## 4.1 Reactivity

- `ref()` voor primitieve waarden (gebruik `.value` in script, niet in template)
- `reactive()` voor objecten/arrays (optioneel)
- `computed()` voor afgeleide waarden (automatisch gecached)

## 4.2 Props & Emits

```javascript
const props = defineProps({
  project: { type: Object, required: true },
  darkMode: { type: Boolean, default: true },
})

const emit = defineEmits(['click', 'delete'])
emit('click', props.project)
```

## 4.3 Lifecycle

- `onMounted()`: Wanneer component in DOM is (gebruik voor localStorage laden)
- `onUnmounted()`: Cleanup
- `watch()`: Voor specifieke dependencies

# 5. Tailwind CSS

## 5.1 Regels

- **Gebruik Tailwind utility classes** waar mogelijk
- **Vermijd custom CSS** tenzij echt nodig
- **Dynamic classes**: gebruik `:class` binding of computed properties
- **Volgorde**: Layout → Spacing → Sizing → Typography → Visual → Interactivity

## 5.2 Responsive Design

- **Mobile first**: Base styles voor mobile, dan `md:`, `lg:` voor groter
- **Breakpoints**: sm (640px), md (768px), lg (1024px), xl (1280px)
- **Grid**: `grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-6`

## 5.3 Dark Mode Pattern

```javascript
const darkMode = ref(true)
const bg = computed(() => (darkMode.value ? 'bg-zinc-950' : 'bg-gray-50'))
const card = computed(() => (darkMode.value ? 'bg-zinc-900' : 'bg-white'))
```

# 8. Veelvoorkomende Patterns

## 8.1 LocalStorage

```javascript
// Opslaan
localStorage.setItem('wireframe_projects', JSON.stringify(projects.value))

// Laden (in onMounted)
const saved = localStorage.getItem('wireframe_projects')
if (saved) projects.value = JSON.parse(saved)
```

## 8.2 CRUD

- **Create**: `projects.value.push({ id: Date.now(), ...data })`
- **Read**: Load in `onMounted()`
- **Update**: `projects.value[index] = { ...old, ...updates }`
- **Delete**: `projects.value.filter(p => p.id !== id)`
- **Altijd opslaan in localStorage na mutatie**

## 8.3 Search/Filter

```javascript
const searchQuery = ref('')
const filtered = computed(() =>
  items.value.filter((item) => item.name.toLowerCase().includes(searchQuery.value.toLowerCase())),
)
```

## 8.4 Toast Notifications

```javascript
const showToast = ref(false)
const toastMessage = ref('')

const showNotification = (msg) => {
  toastMessage.value = msg
  showToast.value = true
  setTimeout(() => (showToast.value = false), 3000)
}
```

## 8.5 Export JSON

```javascript
const blob = new Blob([JSON.stringify(data, null, 2)], { type: 'application/json' })
const url = URL.createObjectURL(blob)
const a = document.createElement('a')
a.href = url
a.download = `${name}.json`
a.click()
URL.revokeObjectURL(url)
```

# 11. Performance

- Altijd `:key` bij `v-for` (gebruik unieke ID, niet array index)
- `computed()` voor waarden die vaak gelezen worden (gecached)
- Methods voor acties/events
- Vermijd inline arrow functions in `v-for` (creëert nieuwe functie elke render)
